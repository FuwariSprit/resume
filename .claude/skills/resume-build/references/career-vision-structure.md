# キャリアビジョン欄の構成フレームワーク

レジュメの「キャリアビジョン（野望）」欄の**文章の並べ方**を定めた参照。
「何を書くか（内容要件）」は resume-build SKILL.md と `docs/career-vision.md` が持ち、
このファイルは「どう並べて読ませるか（構成の骨格）」だけを扱う。両者は補完関係にある。

うまく書けているキャリアビジョン1例を構造だけ抽出したもので、**特定の思想には依存しない**。
誰のビジョンでも、このブロック順に沿えば「読ませる」流れになる、という骨格を残す。

文体（常体・改行の入れ方など）は [`writing-style.md`](./writing-style.md) が正。
このファイルは構成のみを定義し、文体には踏み込まない。

## 全体の骨格：6ブロック

上から順に並べる。抽象度は「最抽象 → 感情の核 → 具体の行動 → 情緒的な到達」と動き、
時間は「過去（原点）→ これまで → 現在の志向 → これから」と流れる。
**過去に根を張ってから未来を語る**のが全体の型。

| # | ブロック | 役割 | 書くべき項目 |
| --- | --- | --- | --- |
| 0 | **一言（キャッチコピー）** | 冒頭に独立した一文で結論を言い切る。読み手が最初に掴む像 | 「[どんな立場・手段で] + [誰に] + [どんな価値・変化を] 残したい」を一文で。意志表現（〜したい）で終える |
| 1 | **根底の動機と原点** | なぜそう思うのか、の感情的な核。一貫性を示す | ①いつから／何が好きか（できるだけ古い個人史に接続し「変わらない」ことを示す）②自分にとっての幸福・喜びの定義を自分の言葉で |
| 2 | **手段の選択理由** | なぜこの領域・職なのか、の必然性 | ①選ばなかった／通ってきた別の道（比較対象）②いまの手段を選ぶ決め手を1つのキーワードに集約 ③それで何を実現したいか |
| 3 | **ありたい姿の宣言** | 凡百との差別化。抽象的な to-be を一文で | 「単に〜ではなく、〜」の対比構文。①否定する水準（ありがちなレベル）②目指す一段上の水準 |
| 4 | **具体的な注力ポイント** | 抽象宣言を行動レベルに分解し、宣言倒れを防ぐ | 「具体的には」で受け、2〜3点を **[見出し語（体言）] + [それが何を意味する行動か]** の形で。各点が独立した価値軸になるように |
| 5 | **締め（到達したい瞬間）** | 冒頭の一言に呼応して閉じる。情緒的な到達像 | ①実現したい瞬間を**ユーザー視点のセリフ**で置く（例:「〜があって良かった」）②それを何の力で成すか |

## 貫く傾向（横断的な特徴）

構成を「らしく」しているのはブロックの中身よりこの5点。適用時にも意識する。

1. **抽象→具体→再抽象**：一言（0）で抽象的に掴ませ、注力点（4）で具体に落とし、
   締め（5）で再び情緒的な抽象へ戻す。全体が冒頭と末尾で呼応して閉じる。
2. **過去起点**：先に原点（1）と歩んできた道（2）を語り、その延長として未来を置く。
   いきなり将来像から入らない。
3. **対比構文で差別化**：少なくとも2箇所（手段の選択＝別の道⇔いまの手段、
   ありたい姿＝ありがち⇔目指す姿）で「〜ではなく〜」を作る。
4. **感情語を各ブロックに置く**：幸福・魅力・心地よい・良かった、のような語を要所に置き、
   理屈だけの説明にしない。
5. **宣言は必ず具体で裏付ける**：抽象的な志向（3）を言いっぱなしにせず、
   直後に箇条2〜3点（4）で行動レベルの裏付けを付ける。

## 転職ドラフト向けの補強ポイント（重要）

抽出元の1例は「思想・原点・情緒」に厚く、**転職レジュメで企業が判断に使う次の3点が弱い**。
このフレームワークをそのまま自分に適用すると同じ穴が空くので、骨格に以下を差し込む。
（判定基準は `resume-vision-reviewer` のチェック項目、内容要件は resume-build SKILL.md「キャリアビジョン」。）

- **具体的な役割・立ち位置**（reviewer 項目1）：ブロック4の注力点、またはその直後に、
  3〜5年後にどの立ち位置・領域で働いていたいかを差す。「成長したい」で終えない。
- **時間軸**（reviewer 項目4）：短期（次の職場ですぐ）と中長期（3〜5年後）を区別する。
  短期はブロック4に、中長期はブロック4〜5のつなぎに置くと収まりがよい。
- **過去の具体案件への接続**（reviewer 項目3・最重要）：ブロック1・2の原点は
  幼少期など抽象に寄りがちなので、`docs/career-vision.md`「由来する経験」にある
  **業務の具体案件**を最低1つ、ブロック2かブロック4に結び付ける。
  経験と切り離された願望は実現可能性を判断できず説得力を持たない。

## 適用手順

1. `docs/career-vision.md` を読み、下の対応で各ブロックの素材を拾う。

   | ブロック | 主に対応する `docs/career-vision.md` の節 |
   | --- | --- |
   | 0 一言 | 「志向性」＞「『一言で言うなら』についての示唆」 |
   | 1 原点 | 「志向性」「由来する経験」＞業務経験より前からある土台 |
   | 2 手段の選択 | 「由来する経験」「目指す役職・関わりたい領域」 |
   | 3 ありたい姿 | 「志向性」「3〜5年後にどうありたいか」 |
   | 4 注力点 | 「次の職場で短期的にやりたいこと」「目指す役職・関わりたい領域」 |
   | 5 締め | 「志向性」の核＋「参考にしている人・キャリア」で描く理想像 |

2. ブロック0→5の順で下書きし、「貫く傾向」5点を満たしているか見る。
3. 「補強ポイント」の3点（役割・時間軸・案件接続）が骨格に入っているか確認する。
4. 文体は `writing-style.md` に合わせて整える。
