# docs/projects

案件ごとの棚卸しを置く場所です。レジュメの職務経歴は、ここに記録した事実だけを元に作成します
（[`docs/README.md`](../README.md) を参照）。

- 新しい案件のメモを作るときは [`_template.md`](./_template.md) をコピーして使ってください
- ファイル名は `YYYY-案件スラッグ.md`（例: `2025-seo-risk-check-feature.md`）のように、
  開始時期がわかる形を推奨します
- `/resume-interview <案件名>` で対話しながら埋められます
- ここに書いた内容がすべてレジュメに載るわけではありません。何を載せるかは
  `/resume-build` と `/resume-review` を経て決めるので、この段階では省かずに書き出してください
